# Flower OMS — продуктовый анализ

*Дата: 24.09.2026. Ветка анализа: `v1-hardening` (коммит `a481832`).*

## Как проводился анализ

- Прочитан весь код в `src/` и `prisma/`, а также README.md и SETUP.md. **CLAUDE.md в репозитории нет**, поэтому правила проекта взяты из SETUP.md.
- Проект запущен на отдельной демо-базе: portable MariaDB на порту 3307, база `flower_oms_demo`, данные из `npm run db:seed-demo`. Рабочая база не использовалась.
- Через Playwright пройден полный день магазина за каждую роль, на ширине 1280 и 390 px. Скриншоты лежат в [`docs/screens/`](./screens).
- Пометка **«проверено»** значит, что проблема воспроизведена в браузере. Пометка **«по коду»** значит, что она найдена при чтении кода.

**Исходные допущения.** Владелец попросил сделать продукт «максимально универсальным». Поэтому анализ не привязан к одному магазину. Предполагается, что система должна подходить:

- и одному магазину, и сети из нескольких точек;
- для заказов из любых каналов: звонок, WhatsApp, Instagram, сайт, покупатель в зале;
- для любых способов оплаты: наличные, карта, перевод, онлайн, предоплата, долг;
- для любой доставки: свои курьеры, такси, внешние службы, самовывоз;
- для интерфейса на азербайджанском и русском языках.

## 1. Идея и ценность продукта

1. Flower OMS — система учёта заказов для цветочного магазина. Она проводит заказ от звонка клиента до вручения букета и оплаты.
2. Пользователей три роли: **оператор** (колл-центр или продавец) принимает заказ и деньги, **флорист** собирает букет и списывает цветы, **администратор** управляет складом, сотрудниками и отчётами.
3. Проблема, которую решает система: в магазине заказы ведут в тетради, WhatsApp и голове. Из-за этого забывают сроки, путают, кто собирает букет, теряют деньги по долгам и не понимают, куда уходят цветы.
4. Система даёт одно общее место для заказа. В нём есть фото-образец, срок, ответственный флорист, фото готового букета, история действий и оплата, в том числе смешанная и в долг.
5. Для владельца ценность в контроле: видно выручку, долги, расход цветов и работу флористов. Это можно выгрузить в Excel.

## 3. Что работает хорошо

- **Безопасность на хорошем уровне.** Роли проверяются на каждом запросе к базе, деактивированный пользователь сразу выходит из системы. Фото отдаются только авторизованным, проверяется содержимое файла. CSV защищён от формул Excel.
- **Деньги считаются в копейках** (`toCents`). Строка заказа блокируется при оплате (`FOR UPDATE`), поэтому переплатить двумя параллельными платежами нельзя.
- **Флорист берёт заказ атомарно:** два флориста не получат один заказ.
- **Склад списывается транзакционно**, каждое изменение пишется в `StockEvent`.
- **История заказа полная:** кто, когда и что сделал, включая оплаты и отмены оплат.
- **Телефоны нормализуются** (`+994…`), клиенты создаются автоматически при первом заказе.
- **Экран флориста удобен на телефоне:** крупный шрифт, кнопки ±, фото прямо с камеры.
- **Панель оплаты понятна:** нал, карта, смешанная, долг, остаток к оплате.
- Типы проверяются (typecheck), lint без ошибок, сборка проходит.

## 5. Чего не хватает по сравнению с типичными системами для цветочных магазинов

| Функция | Сейчас | Зачем магазину |
|---|---|---|
| **Закупки и приход** (поставщик, цена, партия) | Нет | Понимать, сколько потрачено и что докупить. |
| **Списание брака** с причиной | Нет, только перезапись числа | Цветы вянут, а потери сейчас не видны. |
| **Себестоимость и маржа букета** | Нет цен закупки | Главная метрика для цветочного бизнеса. |
| **Каталог букетов** (шаблон, фото, цена, состав) | Нет, сумма вводится вручную | Быстрый заказ и продажи через сайт или Instagram. |
| **Курьеры**: назначение, маршрут, статус с фото | Нет | Контроль доставки и оплаты курьеру. |
| **Получатель и текст открытки** | Нет | Есть почти в каждом цветочном заказе. |
| **Печать открытки и чека** | Нет | Флорист печатает открытку, курьер берёт накладную. |
| **Напоминания о праздниках клиентов** (день рождения уже хранится) | Поле есть, напоминаний нет | Повторные продажи: «через 3 дня день рождения у мамы клиента». |
| **Уведомления клиенту** (WhatsApp, SMS: принят, готов, доставлен + фото) | Нет | Меньше звонков «где мой букет». |
| **Онлайн-приём заказов** (форма, ссылка для Instagram и WhatsApp) | Нет | Новый канал продаж без оператора. |
| **Касса и смена** (открыть, закрыть, Z-отчёт) | Нет | Сверка наличных с продавцом. |
| **Скидки, бонусы, промокоды** | Нет | Лояльность постоянных клиентов. |
| **Несколько филиалов** | Нет | Сеть магазинов, общий склад. |
| **Второй язык интерфейса (русский)** | Только азербайджанский | Персонал и владельцы часто говорят по-русски. |

## 6. Как на этом зарабатывать: SaaS для магазинов Азербайджана

**Рынок.** В Баку и регионах сотни цветочных магазинов и студий, большинство работает через WhatsApp и Instagram без системы учёта. Сильные стороны продукта для этого рынка:

- интерфейс на азербайджанском;
- цены в манатах;
- номера телефонов в формате +994;
- работа с телефона.

**Что нужно сделать, чтобы продавать:**

1. **Мультиарендность.** Модель `Shop` (tenant), поле `shopId` во всех таблицах и изоляция данных. Поддомен или слаг для каждого магазина.
2. **Самостоятельная регистрация.** Мастер: магазин → админ → первые цветы → первый заказ. Демо-данные по кнопке.
3. **Тарифы и оплата подписки** через местный эквайринг (например, Payriff, Epoint или банковский), счёт для юрлиц.
4. **Настройки магазина:** название, логотип, часы работы, зоны доставки, способы оплаты, шаблоны сообщений.
5. **Хостинг и надёжность:** облако, ежедневные бэкапы базы и фото, мониторинг, политика конфиденциальности (персональные данные клиентов).
6. **Функции, за которые платят:** онлайн-витрина и форма заказа, WhatsApp-уведомления, напоминания о праздниках, маржа букета, курьеры.
7. **Поддержка и обучение** на азербайджанском: [USER_GUIDE_AZ.md](./USER_GUIDE_AZ.md) и видео.

**Ориентировочные цены подписки** (гипотеза, проверить на 5–10 магазинах):

| Тариф | Для кого | Что входит | Цена в месяц |
|---|---|---|---|
| **Start** | Небольшая студия | 1 точка, до 3 сотрудников, заказы, оплаты, склад, отчёты | ~29 AZN |
| **Biznes** | Магазин с доставкой | Безлимит сотрудников, курьеры, WhatsApp-шаблоны, напоминания, маржа, онлайн-форма | ~59 AZN |
